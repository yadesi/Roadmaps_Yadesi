## Tooltip UI - (EN)

In this project, you are I've created a tooltip that appears above navigation items when hovered, using only HTML and CSS.
A tooltip is a small pop-up box that provides additional information about a navigation item when a user hovers over it.
This project will focus on mastering CSS positioning, hover effects, and creating visually appealing tooltips without relying on JavaScript.

### Purpose

The goal of this project is to help me understand how to use CSS for dynamic UI effects. You will learn how to position elements relative to each other,
create smooth transitions, and make your navigation more interactive and user-friendly.

## Interface utilisateur des infobulles - (FR)

Dans le cadre de ce projet, j'ai créé une infobulle qui s'affiche au-dessus des éléments de navigation lorsque l'on passe la souris dessus, en utilisant uniquement du HTML et du CSS.
Une infobulle est une petite fenêtre contextuelle qui fournit des informations supplémentaires sur un élément de navigation lorsque l'utilisateur passe la souris dessus.
Ce projet vise à maîtriser le positionnement en CSS, les effets au survol et la création d'infobulles visuellement attrayantes sans recourir à JavaScript.

### Objectif

L'objectif de ce projet est de m'aider à comprendre comment utiliser le CSS pour créer des effets dynamiques dans l'interface utilisateur. Vous apprendrez à positionner des éléments les uns par rapport aux autres,
à créer des transitions fluides et à rendre votre navigation plus interactive et plus conviviale.

- lien : https://roadmap.sh/projects/tooltip-ui
