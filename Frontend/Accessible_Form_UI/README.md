## Accesible Form UI - YADESI - (EN)

In this project I created a form UI using only HTML and CSS. The form will include fields for a full name, email, password,
and confirm password, along with a button to toggle the visibility of the password text.
Additionally, the form will feature a completeness progress bar and a checklist of requirements that must be met for
the form to reach 100% completeness. While this version of the form won’t be functional, it will be a static UI component
that can be enhanced with JavaScript in the future.

The goal of this project is to not only help you practice your HTML and CSS but also to focus on creating an accessible
form that is easy to use for all users, including those with disabilities.

## Interface utilisateur accessible - (FR)

Dans le cadre de ce projet, j’ai créé une interface utilisateur de formulaire en utilisant uniquement du HTML et du CSS. Le formulaire comprendra des champs pour le nom complet, l’adresse e-mail, le mot de passe,
et la confirmation du mot de passe, ainsi qu’un bouton permettant d’afficher ou de masquer le texte du mot de passe.
De plus, le formulaire comportera une barre de progression indiquant le niveau de complétude et une liste de critères à remplir pour que
le formulaire atteigne un taux de complétude de 100 %. Bien que cette version du formulaire ne soit pas fonctionnelle, il s’agira d’un composant d’interface utilisateur statique
qui pourra être amélioré à l’avenir à l’aide de JavaScript.

L’objectif de ce projet est non seulement de vous aider à vous exercer au HTML et au CSS, mais aussi de mettre l’accent sur la création d’un formulaire accessible
et facile à utiliser pour tous les utilisateurs, y compris les personnes en situation de handicap.
