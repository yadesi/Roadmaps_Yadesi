## Datepicker UI (EN)

As part of this project, I am creating a simple user interface for selecting a date,
using only HTML and CSS. This will not be a fully functional date picker, but rather a
static user interface component that I could subsequently enhance using JavaScript.

The goal of this project is to practise positioning, layout and styling techniques in CSS.
